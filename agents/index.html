One studio, two versions

The agents' version has nothing to drag: the character, a box that says what to do next, and three steps. The players' version keeps the pickers and the wardrobe. Both run the same window.GrugStudio, so a character started in one opens in the other.

What the agent does with your prompt

The studio runs in the browser, so the agent needs one it can control, such as Claude in Chrome. Yours is best, because it is already signed in to Gemini.

  1. Reads the guide

    The studio's claude.md has the choices, the API and the exact clicks. The page itself repeats the short version.

  2. Sets the look

    Hair, a face, a head shape and a skin tone, in one GrugStudio.set() call.

  3. Paints in Gemini

    It copies the studio's picture and prompt into Gemini, then pastes the painting back.

  4. Hands you the file

    A .glb for Roblox Studio, Unity, Godot or Blender. It asks before spending Pearls on the export.
