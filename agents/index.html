Your agent makes the cast and the town

Grug Avatar Studio and Building Studio are written for AI agents. Send one prompt to Claude, or any agent that can use a browser, and get back a rigged Roblox R6 character or a textured building as a .glb.

Or paste a studio's link into a chat and say what you want. The page tells the agent what to do.

Characters that wear what you described

An agent left alone builds a character out of grey boxes. With Avatar Studio it picks hair and a face, has Gemini paint a shirt and pants from your description, and hands you a rigged R6 character.

A real R6 rig

HumanoidRootPart, Torso, Head, arms and legs, so R6 animations and Humanoid movement work once it's set up in Studio.

A painted outfit

Gemini paints the shirt and pants from a description. You also get shirt.png and pants.png classic templates.

An API for the agent

window.GrugStudio sets the look, opens the painting steps and exports. Recipe links cover agents with no browser.

Buildings from a few numbers and one sentence

The agent sets a width, depth, height and roof, then writes what the building is. Building Studio draws a colour-coded sheet, Gemini paints it, and the painting is baked back onto the model.

What the agent does with your prompt

Both studios run in the browser, so the agent needs one it can control, such as Claude in Chrome. Yours is best, because it is already signed in to Gemini.

  1. Reads the guide

    Each studio has a claude.md with the settings, the API and the exact clicks.

  2. Sets it up

    Hair, face and skin for a character. Size, roof, doors and windows for a building.

  3. Paints in Gemini

    It copies the studio's picture and prompt into Gemini, then pastes the painting back.

  4. Hands you the file

    A .glb for Roblox Studio, Unity, Godot or Blender. It asks before spending Pearls on a character export.

Install once and stop pasting

A skill tells Claude to reach for the studio on its own whenever a game needs characters or buildings. Add the zip as a skill in Claude, or unzip it into ~/.claude/skills/ for Claude Code.

roblox-characters

Plans the cast, makes each character in Avatar Studio, then imports and rigs them in Roblox Studio or a Rojo project.

Download the skillRead SKILL.md

game-buildings

Plans the buildings, makes each one in Building Studio, then brings the files into Roblox Studio, Unity, Godot or Blender.
